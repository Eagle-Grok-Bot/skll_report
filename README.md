# skll_report — HEP progress report skill (Amber baseline)

Reusable skill for JUNO / HEP conference and collaboration reports.

**Style floor:** the author’s own Amber talk and poster (see Indico links in `SKILL.md`; text mirrors under `refs/`).

## Two-step gate (required)

1. **Step A — Direction + outline HTML**  
   Discuss report direction with the user → produce one HTML file with the full outline and each page’s **core content** → **wait for user confirmation**.

2. **Step B — Per-page prep** (only after Step A is confirmed)  
   Expand each page, discuss figures, collect **PNG/PDF**, place plots, optional nightly schedule.

Do not start deep per-page drafting before the outline HTML is approved.

## Files

- `SKILL.md` — full recipe  
- `examples/outline-html-template.html` — Step A gate artifact layout  
- `examples/figure-inventory-template.md` — figure discuss → file → place tracker  
- `examples/` — talk/poster/abstract outlines, nightly plan  
- `refs/` — Amber text extracts (style anchors)
