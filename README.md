# skll_report — HEP progress report skill (Amber baseline)

Reusable skill for JUNO / HEP conference and collaboration reports.

**Style floor:** the author’s own Amber talk and poster (see Indico links in `SKILL.md`; text mirrors under `refs/`).

## Workflow (summary)

0. **Intake** — meeting calendar + report plan  
1. **Structure** — discuss outline per venue (Amber spine; other guides only for timing)  
1b. **Figures** — discuss each plot’s meaning → user sends **PNG or PDF** → place in draft  
2. **Nightly plan** — schedule what to write each night until the deadline  
3. **Draft** — Amber voice (physics-first bullets, numbers vs baselines, short summary)

## Files

- `SKILL.md` — full recipe  
- `examples/` — talk/poster/abstract outlines, nightly plan, **figure inventory**  
- `refs/` — Amber text extracts (unchanged style anchors)
